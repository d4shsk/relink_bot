# relink_bot

Простой Telegram-бот, который на **любое** сообщение пользователя отвечает
уведомлением о переезде. Работает в двух режимах, переключаемых переменной
окружения `RELINK_MODE`.

## Режимы

### `maintenance` (по умолчанию)

На время техработ и миграции credits ссылки на нового бота **не показываются**,
чтобы не увести пользователей до завершения переноса данных.

> 🛠 Идут технические работы.
>
> Мы переезжаем на новый сервер. Все ваши данные и подписки сохранены.
>
> Пожалуйста, загляните чуть позже 🙏

### `live`

После завершения миграции — полное сообщение со ссылками.

> 👋 Бот и сайт теперь тут!
>
> Все ваши данные и подписки сохранены.
>
> Переходите по ссылкам ниже 👇

Кнопки под сообщением:

- 🤖 [@anywai_bot](https://t.me/anywai_bot)
- 🌐 [chat.anywai.ru](https://chat.anywai.ru/)

Переключение режима — смена `RELINK_MODE` в `.env` и перезапуск бота.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота:

   ```bash
   cp .env.example .env
   ```

   ```env
   TELEGRAM_TOKEN=ваш-токен-от-BotFather
   RELINK_MODE=maintenance
   ```

3. Запустите бота:

   ```bash
   python bot.py
   ```
